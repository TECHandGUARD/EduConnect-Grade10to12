# GuardCommerce

Multi-merchant commerce platform by Tech & Guard.

## Status
Foundation scaffold, **not production ready**. No payment processing or merchant isolation has been implemented yet.

## Development
Requires Node.js 20+.

```bash
npm install
npm run dev
```

## Roadmap
- Merchant authentication and tenant isolation
- Product and inventory management
- Storefronts, cart, checkout and orders
- Yoco payment verification and webhooks
- Subscription billing, themes and custom domains

Never place payment secret keys in client-side environment variables.
